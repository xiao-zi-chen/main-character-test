2. 在 main-character-test/ 首次运行 npm ci，然后运行 npm run dev。
3. 构建后可运行 npm run preview；dev 和 preview 都代理本机 127.0.0.1:3000。
4. 按终端显示的地址访问；根服务提供采集 API 与 public-config.js 运行时配置。
5. 未启动根服务时只能预览页面，采集队列暂存在浏览器中，无法入库。
Windows PowerShell 可使用 npm.cmd 执行上述命令。
