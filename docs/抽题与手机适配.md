# 二十题抽样版

- 题库保留 40 个稳定 ID 和原评分方向，展示文案在 `src/data/question-copy.js` 中统一更新。
- 每个性格维度不放回抽取 2 道，再随机打乱全局顺序；本轮总计 20 道。
- 每个维度的分数只基于本轮抽中的两道题计算，不以未抽中的题为零分。
- 本轮 ID、顺序、答案、位置及提交状态使用浏览器存储键 `main-character-casting:v3`，数据版本为 3。刷新和返回保留同一轮，重新开始生成新一轮；旧版 40 题记录不会被当作新答卷。
- 全部 20 个角色，包括两种隐藏结果，仍可从抽样答卷命中。相同答案和题目始终生成相同结果。不同抽样会带来正常的结果波动，本产品是剧情娱乐测试。
- 手机竖屏以 `100dvh` 展示单题，去掉答题过程中的大导航和页脚。小于 520px 高的横屏允许滚动，避免为了塞进一屏而裁掉内容。

## 采集接口约定

采集脚本仍在明确点击下一题时记录一次答复；拖动滑杆或点击选项只更新本地草稿。

新会话的 `questionnaireVersion` 为 `nbti-2026-10-15-sample20`。`session.questionIds` 是本轮按展示顺序排列的 20 个唯一 ID。服务端需要验证这些 ID 属于 40 道题库，每个维度恰好两道，所有事件属于当前题目集，并在全部所选 ID 均有答复后接受 `completedAt`。

旧版 `nbti-2026-10-02-scale15` 待同步记录保留在原有队列中，仍按旧版协议发送，不伪装成新的 20 题记录。匿名身份不变。前端不会因为网络同步失败阻止本地作答与结果展示。

该仓库只提供前端和采集客户端，真实 Node/MySQL 服务由外部 NBTI 项目提供。上线采集前需在该项目增加新协议支持，并更新正式题库展示文案；本地浏览器验证不等于服务端已接受新协议。
