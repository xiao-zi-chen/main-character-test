# 前端体验验收

本轮改动继续保持精简首页，不增加角色目录的公开入口。

## 已处理

- 首页封面不再因为异步媒体清单加载而重复请求；媒体清单随前端构建发布。
- 结果页只加载封面，点击才请求视频。竖屏和横屏使用独立播放器，支持声音开关、下载、加载提示与失败重试。
- 手机上的结果操作移到整行，按钮文案缩短；看完搭档可直接返回自己的结果。
- 弹窗使用原生模态对话框，键盘焦点留在弹窗内，关闭后恢复到触发按钮。
- 修复角色弹窗主按钮对比不足、横屏视频控制裁切、页面获得焦点时出现整页边框的问题。
- 系统分享可用时优先打开手机分享面板；取消不报错，不可用时回退到复制或手动选择邀请。
- 答题记录未保存时显示可重试提示并保留选择；本地存储被禁用时仍可完成当前页面内的流程。
- 清理旧首页、旧分类目录与二选一答题界面的过期样式，统一现有页面配色。

## 验证范围

- `npm test`：19 项单元测试。
- `npm run test:e2e`：桌面和手机尺寸共 40 项有效浏览器检查，3 项因设备类型不适用而跳过。
- 所有 40 道题在 320×568 和 390×844 竖屏检查题干、选项、量表与下一步的边界。
- 20 个角色的媒体完整性和角色卡画像逐像素检查。
- 新增 `resilience.spec.js` 覆盖重复资源请求、弹窗焦点与颜色、横屏控件、视频失败重试、记录失败、禁用存储及取消原生分享。
- 额外使用 Playwright WebKit 的 iPhone 尺寸完成首页、弹窗、20 次触屏回答、结果、声音播放、搭档返回及刷新恢复检查。
- `npm run build` 与 `node scripts/verify_deployment.mjs` 验证发布构建和二十套媒体。

以上移动端检查基于浏览器模拟，不等同于真实 iPhone 或微信内置浏览器验收。外部采集服务与数据库不在本仓库，本轮未验证正式环境入库。
