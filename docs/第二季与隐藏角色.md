## 隐藏角色操作

1. 首页默认显示十八个常规角色和两个不透露身份的占位卡。
2. 连续点击左上角「主角请就位」五次，进入「彩蛋导演室」。鼠标、触屏及键盘激活链接都可使用。
3. 开启「允许解锁隐藏剧本」。开关默认关闭，开启本身不会直接揭晓身份。
4. 完成全部四十题并查看自己的结果。如果答案满足下表，揭晓对应隐藏角色，并在此浏览器记录解锁。
5. 刷新后仍能查看已解锁身份；关闭开关会停止新的隐藏匹配，但保留已有收藏。
6. 点击「清空彩蛋记录并关闭」会清空解锁记录并关闭开关。未解锁的直接链接返回不透露身份的提示页。

以下为创作与维护资料，不在常规图鉴展示：

| 隐藏角色 | 解锁条件（均为高向量表倾向，阈值保持原样） |
| --- | --- |
| 天道后台管理员 | 观点坚持≥75、节奏规划≥75、规则自由≥75、目标定力≥75、社交能量≤40 |
| 宇宙片场总导演 | 未知探索≥75、脑洞联想≥67、社交能量≥80、规则自由≥75、目标定力≤25 |

两组条件不会同时成立。开关关闭时一律在十八种常规角色中匹配；开启但未满足条件时也正常返回常规结果。没有付费解锁、随机概率或“比普通人更优秀”的等级含义。

隐藏链接仍要求访问者自己的浏览器已解锁；想直接展示自己的隐藏结果，可以下载角色卡分享。所有状态保存在本机 `localStorage`。这是静态网站中的游戏流程，并非服务端访问控制；不能用来保护敏感资料。
