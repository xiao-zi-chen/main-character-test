- 播放器占满浏览器可视区域（包含横屏），保留原视频比例；只有右上角关闭按钮。取消标题、时长、进度条、音量与下载按钮。视频保留声音，自动播放受限时可轻触画面播放。

## 重新生成角色卡

修改人物、画像、分享卡布局后，在仓库根目录启动开发服务器：

```powershell
$env:NBTI_DEV_BACKEND='disabled'
npm run dev -- --port 5281 --strictPort
```

另一个终端运行：

```powershell
node scripts/export_role_cards.mjs
npm run build
node scripts/verify_deployment.mjs
```

重新运行 `build_selected_catalog.py` 后也必须重新导出角色卡，因为媒体清单会被重建。卡片导出默认使用本机 Edge 和 5281 端口，可用 `CARD_EXPORT_URL` 指定开发服务地址。旧卡文件不会自动删除，发布白名单仅包含当前清单引用的文件。

此前四条影片重制及 120 张题图重绘仍未执行；本次只调整播放器行为，未修改原片对白或分镜。线上生产站点与外部采集后端未在本次部署。
