结果页只展示当前匹配的人物，移除了同片人物切换区和搭档人物区。人物目录及每个人独立的网址仍可访问；计分、28 人的匹配关系和 17 条原片保持原有数据。

## 直接看图片

打开 [五档题图预览](五档题图预览.html)，可选择全部 40 道题，查看每题的 3 张题干／端点图及 5 张反应图，并点击放大。预览依赖同一仓库内的 `public/question-art/`，需保留相对目录。

![五档反应图预览](assets/five-degree-preview.png)

[查看手机答题页面](assets/five-reactions-mobile.png) · [查看朋友圈分享面板](assets/share-moments.png)

每题共 8 张，全部由服务器本地 MiniMax H3 独立生成，1152 × 640 WebP，不再从三格分镜中裁切。原有 120 张题图全部替换，新增 200 张五档反应图。每题保留自己的画风、主角和色彩设计；每档用具体动作、物件、注意力及人与人的距离表达程度，配以清晰的颜文字贴纸和中文说明。

例：周末安排从“熟悉的咖啡店”逐步过渡到“看看附近新店”“喝完咖啡观察陶器”“试一次轻松的陶艺体验”“动手做陶艺”。中间档也有完整画面，不用端点图片冒充。

答题前展示题干图，选择 0～4 后上方画面切换到 `scale-0.webp`～`scale-4.webp`；左右端点图仍可点击。刷新和返回上一题恢复已选图片，新题恢复题干图。手机端图片完整显示，题干放在图片下方，不遮住手和关键物件。图片失败保留原文、五档选择和下一步，切到其他档位可继续加载图片。

## 来源与复现

- 动作与文案：`content/question-art-five-actions.json`、`src/data/question-reactions.js`。
- 完整提示词：`content/question-art-five-prompts.json`；实际安装的生产提示词：`content/question-art-production.json`。
- 每张图的任务 ID、种子、尺寸、字节数及 SHA-256：`public/question-art/manifest.json`。
- 基础批次：生成服务器 `outputs/question-art-v7/`；逐图验收后的定向补画在 `outputs/question-art-v8-refined/`，范围见 `content/question-art-refinements.json`，逐图来源以清单为准。初次 v6 试稿发现题干动作影响反应图后，改为仅描述选择后的单一行为；v6 不作为最终发布来源。
- 原图备份：本地 `.work/question-art-before-v6/`；生成服务器保留逐图 PNG 和工作流。

```bash
node scripts/export_question_five.mjs
# 在已有 MiniMax H3 服务器运行；指定新的输出目录，不覆盖已有任务
venv/bin/python generate_question_five.py \
  --prompts question-art-five-prompts.json --output outputs/question-art-new
# 本地：凭据只从进程环境读取，不进入文件或浏览器
python scripts/sync_question_five.py --remote /root/autodl-tmp/minimax-h3/outputs/question-art-new --watch
node scripts/export_question_review.mjs
npm run media:questions
npm test
npm run test:e2e
npm run build
node scripts/verify_deployment.mjs
```

生成器逐图记录完成状态，可以断点继续；未完成的任务保留任务 ID，避免重复提交。同步器校验哈希、尺寸和格式后安装图片，全部 320 张齐备才更新生产清单。SSH 密码通过 `ART_SSH_PASSWORD` 提供，连接检查服务器主机指纹。

复现当前发布的补画时，生成器可以读取仅含补画条目的提示词文件，输出到独立目录。对同目录已完成任务使用 `--refresh-changed`，只重做提示词或种子变化的图片，旧工作流和图片归档到 `.history/`。基础批次同步后执行 `python scripts/install_question_refinements.py`，安装补画前逐项比对服务器实际工作流、提示词、种子和文件哈希。

Vite、部署校验和 ZIP 打包都包含 320 张题图及清单。外部 NBTI 服务及 Nginx 若使用精确文件白名单，也必须加入新增的 `scale-0.webp`～`scale-4.webp`；本仓库不包含该外部服务。图片版本变化会更新缓存参数。五档采集协议和本轮抽题规则不变。
