# 《主角请就位》十种主角 · 5 秒视频生成 Prompt

这十条可分别直接复制到你的视频生成工具。**建议把你提供的参考视频作为风格参考一起上传**，参考它的竖屏近景、真人短剧质感、冲突—反转—结尾定格节奏。人物用下面各条的原创设定，无需复制参考演员的脸。

统一建议：9:16，720×1280 或 1080×1920，5 秒，24fps。每条最多三个镜头，主体放在中间约 70% 区域，底部约 20% 尽量留给网页角色标题。片内不生成汉字、字幕、水印、平台 Logo；人物不说台词，以动作与表情完成反转。先保证画面可懂，音效可后加。

**使用方式：每次复制一条「完整 Prompt」加文末的「通用负面提示词」。**生成视频后按对应文件名保存，替换 `public/media/` 中的同名动态分镜，运行 `npm run media:sync` 并按说明标记为成片。网站会使用本地文件，不依赖外部视频链接。

## 生成后接入网站

1. 将十条成片按上面的英文文件名，放进 `public/media/`，替换同名动态分镜 MP4。保留你下载的原片备份。
2. 执行 `npm run media:sync -- --final all`（全部替换完时），或 `npm run media:sync -- --final myth-keeper`（只替换一条时）。脚本会检查时长和竖屏比例、提取新封面，再更新成片标记。
3. 正在运行开发服务器时刷新页面即可；已构建过的部署版本，需要重新执行 `npm run build`。

如果模型生成的叙事不够稳定，先保住中间的「反转动作」和结尾「人物反应」。可以减少路人、减少镜头，但不要把十个主角都生成成同一种站姿人物写真。
